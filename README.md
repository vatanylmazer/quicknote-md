📝 QuickNote MD (Live Markdown Note Editor)

A minimalist, real-time Markdown note-taking web application featuring live HTML rendering and local storage persistence.

🚀 Features
- Real-time Markdown to HTML conversion powered by Marked.js.
- Clean split-pane workspace (Editor & Live Preview).
- Data persistence using browser LocalStorage.
- Modern dark-mode UI with monospace font support.

🛠️ Built With
- HTML5 & CSS3 (Flexbox, Dark Theme)
- JavaScript (DOM Manipulation, LocalStorage API)
- Marked.js Library

⚙️ Setup & Run
1. Clone this repository to your local machine.
2. Open `index.html` in your browser or run it via Live Server.
